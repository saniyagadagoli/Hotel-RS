# Hotel Registration System (Flask CRUD App)

A simple Flask-based web application to manage hotel guest registrations,
supporting full CRUD (Create, Read, Update, Delete) operations backed by
an SQLite database.

## Features
- Register new guests (Create)
- View all registered guests in a table (Read)
- Edit guest details inline (Update)
- Delete guest records (Delete)
- Flash messages for success/error feedback
- SQLite database auto-created inside the `instance/` folder
- Automatically creates the `hotel_registration` table if it does not exist
